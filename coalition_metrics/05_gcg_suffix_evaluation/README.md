# GCG suffix evaluation

For the concise collaborator handoff, current figures, and the complete Modal checkpoint, start at [`results_paper/README.md`](../../results_paper/README.md). That folder reflects eight completed chronological runs and the partial run 8 checkpoint.

This subproject evaluates whether suffixes learned from Qwen's chronological GCG pilot transfer to other archived contexts, new Qwen games, and GLM/Mixtral. It also compares a direct anti-channel instruction and placebo suffixes.

## Research question

Does a frozen GCG suffix reduce action coordination in `channel_optional` games, and does it do so more reliably than a natural-language instruction or a control suffix?

Keep three outcomes separate:

1. **Prompt-policy alignment:** on replayed prompts, does the suffix make the A/B move distributions closer to the no-channel distributions? This is a distribution proxy, not observed CMI.
2. **Action dependence:** in new complete games, does empirical `I(A;B | S)` move toward the no-channel reference?
3. **Benefit transfer:** do pair advantage `(A+B)/2 − C`, `CS_AB`, channel use, and individual scores change? Do not infer collusion from any one metric alone.

## Reproducibility rules

- Freeze the primary suffix and analysis before the confirmatory campaign. Do not choose the best suffix on the same new games used to report its effect.
- Store raw prompts, raw responses, `config.json`, campaign ID, model revision, seed offset, and the output of each analysis script.
- Treat a complete game as the resampling unit. Rounds within one game are not independent observations.
- Keep the new-game experiment separate from saved-context replay. Replaying an old history does not simulate how the suffix changes later actions and histories.
- Do not call a lower probability-distribution distance an anti-collusion result. Confirm with actions and outcomes from fresh complete games.

No model jobs are launched by these analysis scripts or documentation commands.
